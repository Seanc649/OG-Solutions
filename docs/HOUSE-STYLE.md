# Obsidian house style

This is the style every Obsidian Studio edit copies. It is built the way Nate Herk
built his: measure proven videos frame by frame (the `study-reference` skill), turn
the patterns into numbers and rules, and turn every review note into a new rule
(the `edit-feedback` skill).

**Status: borrowed baseline.** No Obsidian videos have been studied yet, so every
format below starts from the measured baseline in
[EDITING-PLAYBOOK.md](EDITING-PLAYBOOK.md) (Nate's 27 top reels). Replace each
section with Obsidian's own numbers once there are proven videos to study.

Brand: colours and fonts live in `assets/brand-tokens.css` (placeholder values
until the real brand kit arrives). Logo files go in `assets/brand/`.

## Short form: reels, Shorts, TikTok (1080x1920)

Studied: not yet. Using the playbook's "House reel style" as the baseline.

| Measure | Value | Source |
| --- | --- | --- |
| Speech starts | within 0.1 s | baseline |
| Shot length | 1.1 to 1.4 s average, none over about 2.8 s | baseline |
| First cut | 0.6 to 1.0 s, on the first charged word | baseline |
| Pauses between phrases | under about 0.2 s; natural beats 0.2 to 0.4 s stay | baseline |
| Layouts | split (B-roll top, speaker bottom) 30 to 42%, full B-roll 50 to 55%, punch-in 5 to 15% | baseline |
| Speaker off screen | never more than about 3.5 s | baseline |
| Captions | 1 to 3 words, all caps, one dark box style, never over the mouth | baseline |
| Music under voice | about 11 dB below (9 to 14) | baseline |
| Loudness | about -14 LUFS, true peak at or below -1.5 dBTP | baseline |

## Long form: YouTube tutorials and walkthroughs (1920x1080)

Studied: not yet. Baseline from the video this studio was modelled on:

- Two scenes: screen recording with face cam, and full-screen face cam.
- Switch to full-screen face cam when the screen has not changed for a while (the
  mouse is still and the speaker is explaining or telling a story); go back to the
  screen when it starts moving again.
- Zoom into the screen where the viewer needs to read text or see a small detail.
- Cut retakes (keep the last clean take), dead air, and stutters; never cut inside
  a phrase or before a word has fully decayed on the waveform.
- Flag gaps for the speaker: places where an explanation is unclear or a step is
  missing, so they can re-record a line.

To replace: put 3 to 5 representative long-form videos in
`raw-media/references/long-form/` and say "study these long-form videos".
